# Assign Hub Android App

This project wraps the Assign Hub website in a simple Android WebView app.

- App name: Assign Hub
- Website: https://assignhubbyalok.netlify.app/
- Launcher icon: supplied Assign Hub logo
- Minimum Android: 6.0 (API 23)
- Target Android: API 35

## Free APK build with GitHub

1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Open the **Actions** tab.
4. Run **Build Assign Hub APK** (or push a commit).
5. Open the completed workflow run.
6. Download the artifact named **Assign-Hub-debug-apk**.
7. Extract it and install `app-debug.apk` on Android.

The debug APK is suitable for sharing directly with friends for testing.
